- **B**：只能确认标题或搜索摘要；可用于发现线索，不纳入高频统计

## 使用规则

- 原帖中的「我回答……」「正确答案……」及括号解释均视为候选人观点，不进入本语料库的标准答案
- 同一篇帖子里重复追问只计作一个「样本命中」
- 历史帖子用于判断长期稳定题型，不等于当前部门仍固定提问
- 公司名来自作者标题或正文，不代表企业官方确认题库
