## 一面（1h30+min）

1. 自我介绍
2. 项目深挖
3. 计算机网络：TCP、UDP、HTTPS 2.0、DNS 协议、流量控制、拥塞控制
4. HTTP 队头阻塞的解决方式 → HTTP 3.0 使用到的协议
5. 线程中的锁
6. 线程和进程之间的区别
7. 进程之间的通信方式
8. 数据库四大特征、三大范式
9. 设计模式
10. Java 多态、重载与重写

## 二面（1h20+min）

1. 拷打项目
2. HTTP 输入 URL 会发生什么
3. DNS 协议、DNS 缓存
4. 数据库中的索引
5. Android 生命周期
6. Android 的 Activity 之间怎么传送消息
7. TCP 为什么是三次握手而不是两次握手
8. KMP 算法

## 三面（45min）

1. 自我介绍
2. 项目实现过程中的困难及解决办法
3. 研究方向描述、当前方法存在的问题及改进
4. 场景题：如果让你作为一个 leader，如何组建团队

## HR面（15min）

- 当前进展、未来打算、实习时间、目前在面的其他公司
