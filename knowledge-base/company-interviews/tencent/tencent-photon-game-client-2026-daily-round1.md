# 腾讯光子游戏客户端日常实习一面面经（2026）

> 来源：[2026-05-15 原帖](https://www.nowcoder.com/feed/main/detail/d39839bb1e3941fab9a6c4ccce0c3981)
>
> 可信度：A · 招聘类型：游戏客户端日常实习 · 页面日期：2026-05-15

## 一面

1. 自我介绍和项目；C++ 写 UE 的比例，以及具体写了哪些内容。
2. UE 外部输入（如键盘输入）到内部游戏输出的过程。
3. UE 如何回收资源、如何管理对象。
4. UE 的 Tick。
5. UE 的主要线程、各自作用，以及线程间通信。
6. 内存池中对象大小不同时如何管理。
7. 引用指针。
8. 形参和实参。
9. 虚函数和虚表。
10. `new` 与 `malloc`、`delete` 与 `free` 的区别。
11. 进程与线程、进程间通信、线程调度。
12. `inline` 的优缺点。
13. 是否了解 harness engineering、Agent 和多 Agent 通信？
14. 什么时候可以到岗？

## 反问与复盘

1. 面试官介绍业务为游戏中台，为其他项目组提供支持。
2. 反问了能力要求和 AI Coding 相关问题。
3. 面试者复盘认为项目复杂度不足、对 UE 底层了解不够，且需要提升表达的流畅度。
