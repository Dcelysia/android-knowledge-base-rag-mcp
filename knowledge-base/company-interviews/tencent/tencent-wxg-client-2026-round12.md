# 腾讯 WXG 客户端实习一二面面经（面经流，届次待核）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/cab8cab6ee994c318a5bb372468fa52e)
>
> 可信度：A · 招聘类型：客户端实习 · 页面日期：07-06（牛客仅显示月日，届次待核）

## 一面

1. JWT 鉴权协议的优缺点，以及后台主动踢用户下线的实现。
2. 从零搭建简易微信消息系统时的架构和模块设计。
3. 正向代理、反向代理及应用场景；Nginx 反向代理的优缺点和与网关的区别。
4. Java 是否存在智能指针相关概念；Java 对象分配、内存释放和垃圾回收。
5. C++ 虚函数底层实现与掌握的 C++ 知识。
6. 用拓扑排序判断图中是否存在环。

## 二面

1. `localtime` 返回值及示例代码中指针无需手动释放的原因。
2. 手写计算两个日期之间天数的函数，包含闰年判断。
3. 大模型流式输出的原因，以及大模型无法一次性完整生成内容的底层原因。
4. Agent 的 Token 来源、Tools/Skills/MCP 概念和 Skills/Tools 的自动匹配。
5. 微信/QQ 实时推送的底层原理；即时通信服务器向在线客户端推送消息。
6. 用户切换网络导致客户端 IP 变化时，如何保证消息正常推送。
