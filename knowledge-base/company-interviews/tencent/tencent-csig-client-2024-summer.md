# 腾讯 CSIG 客户端三面面经（2024暑期实习）

> 来源：[2024-03-19 原帖](https://www.nowcoder.com/feed/main/detail/f8ae09fc179e4d41ba62b6dd2833b134)
>
> 可信度：A · 招聘类型：CSIG 客户端暑期实习 · 页面日期：2024-03-19

## 三面（约 1 小时）

1. C++、Java、Go 三种语言的区别和特点。
2. C++ 与 Java 在内存管理上的区别。
3. 为什么 C++ 允许手动分配内存，而 Java 使用垃圾回收？
4. 多态的实现原理。
5. C++11 智能指针。
6. `shared_ptr` 的实现原理。
7. `weak_ptr` 为什么能解决循环引用？
8. `weak_ptr` 如何处理指向内存失效的问题？原帖补充可通过 `lock` 升级为 `shared_ptr`。
9. 场景题：基类 A 的构造函数中调用虚函数，派生类 B 重写该函数；创建 B 时打印 A 还是 B 的实现？
10. 项目深挖：两段实习、两个项目、一个科研和一段竞赛，重点追问具体技术实现原理。

> 原帖说明：面试者在讲项目时主动带入计网和操作系统知识，面试官随后主要深挖项目细节。
