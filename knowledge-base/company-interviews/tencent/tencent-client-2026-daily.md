## 一面

### C++ 与基础

1. 左值和右值的区别。回答涉及左值、将亡值、纯右值、所有权和 `move`。
2. 智能指针。优先在所有权明确时使用 `unique_ptr`，并说明 `shared_ptr` 的循环引用与 `weak_ptr` 解决方式。
3. 虚表是什么。说明虚表指针、虚函数入口地址、RTTI，以及 64 位下包含虚函数的空类对象大小。
4. 哈希如何实现。讨论哈希冲突、线性探测、拉链、再次哈希，以及 STL 哈希表的拉链与红黑树。
5. 红黑树与 AVL 树的区别。

### 操作系统与网络

1. TCP 三次握手、四次挥手，以及捎带机制和挥手时的剩余数据发送。
2. 进程和线程的区别；进一步讨论 Windows 与 Linux 的任务模型、`task_struct`、`fork` 多线程进程和锁导致的死锁风险。
3. 什么是线程同步。讨论数据竞争、互斥锁、条件变量、原子变量和内存屏障。

### 项目与算法

1. 介绍操作系统内核实现和游戏工具项目：C++ 控制器调用自部署模型，实时交给 Lua 执行器；Lua 执行器封装 Logitech G Hub API，并实现简易协程。
2. 是否了解 Skills。回答了解 Agent 及相关研究，面试官建议继续了解 Skills。
3. 手撕并查集题 `Redundant Connection II`；第一题未完全写对，面试官认可思路后继续流程。
