# 快手安卓客户端一、二面面经（2023）

> 来源：[2023-09-09 原帖](https://www.nowcoder.com/discuss/529062641008918528)
>
> 质量：A · 招聘岗位：安卓客户端 · 招聘类型：原帖未明确 · 发布日期：2023-09-09

## 一面

1. JVM 内存模型、各内存区域用途、线程共享区域及方法区共享原因。
2. 不会产生 OOM 的区域；垃圾识别和回收算法；GC Roots。
3. 垃圾收集器分类及并行收集器原理。
4. 类和对象的加载过程、双亲委派机制及其优点。
5. 自定义类加载器的方式、用途及生产环境应用。
6. 动态代理和 AOP 的实现，字节码插装方式及生产环境应用。
7. 注解的作用、分类和元注解。
8. Java 多线程问题的本质；`volatile` 的作用与使用场景。
9. 线程池原理、拒绝策略、线程生命周期，以及是否可以直接调用 `stop` 终止线程。

### 算法

- 一面：反转链表二，从第 `n` 个到第 `m` 个节点反转。

## 二面

1. 数据库三范式和分页查询 SQL。
2. 双重校验单例及需要双重校验的原因。
3. View 绘制流程、自定义 View 动画、`invalidate` 与 `requestLayout` 的区别。
4. View 事件分发；子 View 的 `onTouch` 返回 `true` 后是否继续分发。
