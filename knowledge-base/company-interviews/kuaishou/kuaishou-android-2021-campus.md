# 快手 Android 校招三、四面面经

> 来源：[2021-09-28 原帖](https://www.nowcoder.com/discuss/353158636442689536)
>
> 可信度：A（正文可核验） · 招聘类型：校招（届次未明确） · 招聘年份：未明确（发布时间：2021-09-28）

## 三面

本轮主要从项目经历引申，全程围绕项目交流：

1. ButterKnife 实现原理及为什么被弃用。
2. 事件分发机制与滑动冲突。
3. `RecyclerView` 分页加载的实现。
4. Glide 生命周期、缓存机制及缓存清除方法。
5. `RecyclerView` 缓存机制。
6. 算法：字符串转整型，需处理越界。

## 四面

本轮主要考察场景题和发散思维：

1. 学习新知识的方法；遇到困难时如何解决。
2. 如何阅读屎山代码（原帖提到抓包、打印日志、打断点）。
3. 场景题：搜索联系人时后台返回数据量很大，如何处理？网络请求时间长如何解决？原帖讨论了 `shortInfo`、缓存和 HTTP 复用机制。
4. 事件分发场景：一个 ViewGroup 中有两个子 View，手指按下 ViewA，移动到 ViewB 后抬起，分别说明 `ACTION_DOWN`、`ACTION_MOVE`、`ACTION_UP` 的分发流程。
5. 算法：求所有人的空闲时间交集。

输入示例：`[[[3,4],[9,10]], [[3,5],[11,20]]]`；输出：`[[3,4]]`。

作者评价面试官专业、沟通顺畅；四轮技术面共遇到 7 道算法题，未遇到手撕 Hard 题，并在正文末尾许愿 offer。
