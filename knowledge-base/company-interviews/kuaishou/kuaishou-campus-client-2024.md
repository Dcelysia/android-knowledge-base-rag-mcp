# 快手校园招聘客户端面经（2024）

> 来源：[2024-08-27 原帖](https://www.nowcoder.com/feed/main/detail/c7b56d2d9c984c0c94f37f5c11ecfa90)
>
> 质量：A · 招聘岗位：客户端/Android 校招 · 招聘类型：校园招聘，届次未明确 · 发布日期：2024-08-27

## 一面（104 分钟）

1. 自我介绍。
2. 线程与进程的区别、线程安全。
3. HTTP 的实现方式。
4. TCP 与 UDP 的区别；TCP 可靠性、慢开始、拥塞避免、快重传、快恢复。
5. GET 与 POST 的区别，并追问 PUT、DELETE、HEAD。
6. A Activity 跳到 B Activity 时的生命周期；返回、透明 Activity、Dialog Activity、横竖屏切换和 `onConfigurationChanged`。
7. HashMap 源码与扩容条件。

## 算法

- 合并两个有序链表。
- 将一段文本中的单词逆序输出，使用栈和队列。

## 二面（57 分钟）

1. Android 静态库和动态库的区别。
2. Binder 机制、Android 进程间通信。
3. 自旋锁内部实现、线程同步和 `Atomic`。
4. 矩形起点到终点的最短路径，只能向右或向下。

## 三面（40 分钟）

1. 项目难点；`addView` 弹窗耗时和 Fragment 替代方案。
2. Android 绘制流程、ANR 类型/原因/排查、Fragment 与 Activity 的区别。
3. Android 多线程方式、如何停止线程。
4. Handler、Looper、MessageQueue、Message。
5. Java 内存、引用计数和根搜索算法。
6. 32 位整数逆序。

## HR 面

- 基本情况、实习时间和职业规划；原帖记录为口头 Offer。
