## 一面（约 40 分钟）

### Java 与 C++

1. Java 泛型及泛型类型擦除机制。
2. C++ 模板与 Java 泛型的区别。
3. C++ 智能指针：常见类型、自动释放原理，以及两个对象相互引用时如何处理。

### 网络与数据结构

4. HTTPS 的通信原理；HTTPS 加密属于对称加密还是非对称加密。
5. TCP/IP 分层、TCP/UDP，以及 HTTP、HTTPS、FTP、SMTP、DNS 所在层次。
6. 常见 HTTP 状态码。
7. 散列表、操作复杂度和哈希冲突处理。

### 算法

8. 归并排序；原作者记录部分特殊样例未通过。
