## 一面

1. 常见 HTTP 状态响应码；请求超时是哪一个；Cookie 是什么。
2. 反射、使用场景及性能较差的原因。
3. 软引用与弱引用的区别；Android 中的应用；弱引用何时被回收；Handler 持有 Activity 的弱引用时，前台 Activity 是否会被 GC 回收及原因。
4. Kotlin 与 Java 的区别；扩展函数转成字节码的原理；Kotlin 协程挂起和恢复的原理。
5. Lifecycle 的作用与原理。
6. ViewModel 为什么能在屏幕旋转时保证 Activity 数据不丢失，以及 ViewModel 如何存储。
7. LiveData 的 postValue 为什么可能丢值。
8. 设计一个图片请求框架，如何设计缓存。
9. 两堆宝石分别有 12、13 颗，每次只能拿 1—3 颗，拿完者获胜；先手如何保证胜利。
