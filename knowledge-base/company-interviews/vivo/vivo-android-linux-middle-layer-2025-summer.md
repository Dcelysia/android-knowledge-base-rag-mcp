## 岗位方向

- Android 层和 Linux 层之间的中间模块优化或开发。
- 相关技术范围包括 Native C/C++、HAL 适配、缓冲与性能，以及与内核驱动对接。

## 一面问题

1. 介绍一个嵌入式相关项目，说明自己编写了哪些 C/C++ 模块；继续追问模块边界、正确性验证方式，以及负载增大后的瓶颈。
2. 为什么需要区分用户态与内核态；嵌入式/Linux 中哪些操作必须进入内核。
3. Linux 上创建线程相比 `fork` 子进程更轻，主要体现在哪些资源或开销上。
4. 简述虚拟内存和页表；两个进程的虚拟地址相同时，如何映射到不同物理页并互不干扰。
5. 线程在 `read` 上阻塞时内核大致做什么；`select`、`poll`、`epoll` 分别要解决什么问题。
6. 死锁的四个必要条件；工程中固定顺序加锁与 `trylock` 加退避分别适合什么场景。
7. `pthread_cond_wait` 为什么必须放在 `while` 循环中，而不是只用一次 `if` 判断；涉及虚假唤醒和竞态。
8. `#pragma pack` / `__attribute__((packed))` 的利弊；与 DMA、外设寄存器映射、跨平台协议结构体一起使用时的注意事项。
9. C 与 C++ 混编时链接阶段的常见问题：`extern "C"`、name mangling、ABI，以及谁分配谁释放。
10. 系统卡顿或 CPU 占用异常时如何排查；`top`/`htop`、`perf`、`strace`、`/proc` 和日志分级各能看到什么，以及如何逐步缩小范围。

> 原帖其余部分主要是项目准备框架、时间规划和知识点练习建议，未作为面试现场题目补入。
