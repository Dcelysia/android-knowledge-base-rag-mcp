# 美团 24 秋招客户端一面（2023）

> 质量：A · 招聘岗位：客户端，Android/音视频方向 · 招聘类型：2024 届秋招 · 发布日期：2023-08-23

## 一面

1. 硬件视频流推送：CameraX 获取帧、MediaCodec 编码、封装、RTMP/RTSP/HTTP 传输、接收端解封与解码。
2. RTMP 与 HTTP 的区别。
3. OSI 七层模型和 TCP/UDP。
4. OkHttp 请求、Dispatcher 同步/异步队列、线程池和拦截器链。
5. RetryAndFollowUp、Bridge、Cache、Connect、CallServer 等拦截器及顺序。
6. Java 垃圾回收、GC Roots、线程冲突和锁。
7. Android 嵌套滑动、ViewPager/RecyclerView、ScrollView、NestedScrolling。
8. Android 手势响应和事件分发、外部/内部拦截法。
