# 美团客户端一面（2024）

> 质量：A · 招聘岗位：客户端 · 招聘类型：原帖未明确 · 发布日期：2024-07-03

## 一面

1. Java 面向对象特性、接口与抽象类、方法签名冲突。
2. String、StringBuilder、StringBuffer、线程不安全与可见性。
3. 单核 CPU 下的原子性、Java 锁、乐观锁/悲观锁、CAS、死锁排查。
4. IOC 与 AOP。
5. HTTP 基于哪些协议、TCP 三次握手四次挥手、挥手后的 TCP 保留时间。
6. HTTPS 证书的加密方式及获取方式。
7. 类加载生命周期、运行时共享数据、JVM 查询方法。
8. GC 算法、二分/贪心/动态规划/分治及其区别。
9. 快速排序复杂度与稳定性、直接排序复杂度。
10. 两个数组的中位数及优化算法。
11. 不均匀燃烧绳计算 1 小时 15 分钟。
