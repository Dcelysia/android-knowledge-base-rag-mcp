- 原帖说明可线上实习。

## 一面（45 分钟）

1. 自我介绍。
2. 通过什么途径学习？
3. 深挖项目，并给出相关场景题询问解决方案。
4. POST 请求过程；GET 和 POST 的区别；幂等性的含义。
5. HTTP 和 HTTPS 的区别；HTTPS 加密过程及加密算法。
6. 多人合作项目如何协作？
7. 最近看过的一本书。
8. 进程和线程的区别。
9. Android 有几个进程？（原帖作者未答出。）
10. 前端和后端有什么不同？
11. 算法：把字符串转换成整数（`atoi`）。

## 二面（1 小时）

1. 自我介绍。
2. 计算机网络五层结构；TCP、IP 位于哪一层？
3. TCP 和 UDP 的区别及应用场景。
4. 浏览网页、传输文件分别使用 TCP 还是 UDP，为什么？速度和效率如何改进？
5. TCP 流量控制和拥塞控制。
6. 三次握手、四次挥手；第三次握手丢失怎么办；为什么握手三次、挥手四次？
7. HTTP 状态码。
8. 数据库表和视图的区别；视图是否占空间？
9. 项目数据库设计；主键选择；自增和随机数的优缺点。
10. 死锁形成的条件。
11. 面向对象三大特性；什么是多态？
12. `ArrayList` 和 `LinkedList` 的区别及插入时间复杂度。
13. `HashMap` 底层实现及元素插入过程。
14. `==` 和 `equals` 的区别。
15. `HashMap` 是否线程安全；`ConcurrentHashMap` 和 `Hashtable` 的区别。
16. `synchronized` 修饰静态方法与普通方法的区别。
17. Android 生命周期；`onStop` 和 `onPause` 的区别；按 Home、锁屏、弹窗分别触发什么回调？
18. 项目经历及风控策略。
19. 算法：正则表达式匹配。

## 三面（30 分钟）

原帖说明三面未录音，记忆不完整，记录的问题如下：

1. 自我介绍。
2. 从多个角度分析前端和后端的区别。
3. 学习方法。
4. 实习时间等安排问题。

面试官说明本轮主要希望作者理解前后端区别，并了解前端设计思路。
