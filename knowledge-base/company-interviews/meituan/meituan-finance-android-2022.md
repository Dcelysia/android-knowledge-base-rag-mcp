## 一面（55 分钟）

### 常规问题

1. 自我介绍。
2. 为什么选择 Android 客户端岗位？
3. Android 学习路线。
4. 看过哪些编程相关的书籍？
5. 是否写过博客或开源项目？
6. 学习 Android 多长时间？

### Java、Android 与网络

7. `String`、`StringBuffer` 和 `StringBuilder` 的区别。
8. `String` 的内部实现，以及 `String` 对象主要存储在哪一块区域。
9. 重载和重写的区别。
10. `HashMap` 和 `HashSet` 的区别。
11. 手写或说明 `HashSet` 的实现。
12. JVM 运行时数据区。
13. 创建对象的过程。
14. 如何判断一个对象是否应该被回收？
15. 新生代和老年代使用的垃圾回收策略。
16. `Activity`、`Window` 和 `View` 的关系。
17. 如何实现 LRU？
18. HTTP 缓存机制。

### 算法

19. 查找单向链表的中间结点。
20. 查找链表的倒数第 `k` 个节点。

## 二面（60 分钟）

1. 自我介绍。
2. 项目经历深挖；开发项目时遇到过哪些困难，如何解决？
3. 个人职业生涯规划。
4. 希望加入什么样的团队？
5. `HashMap`、`Hashtable` 和 `ConcurrentHashMap` 的区别。
6. 各种布局文件（Layout）的区别。
7. 内存不足时应使用什么字段（该题未回答完整，双方协商换题）。
8. Android crash 的经历及解决方式。
9. Android 内存泄漏场景。
10. Android 点九图的使用（未使用过，协商换题）。
11. 强引用、弱引用、软引用和虚引用的区别。
12. 进程和线程的区别。
13. 线程生命周期。
14. `sleep` 和 `wait` 的区别。
15. 死锁产生的原因。
16. `ListView` 优化措施。
17. 算法：最大子序和。
18. 智力题：用 10L、7L、3L 容器把 10L 水分成两个 5L。

## 三面（75 分钟）

### 常规与项目

1. 除了 Java 还使用过哪些语言（原帖回答 C++、Python）。
2. 项目分工。
3. 意向城市及家乡。
4. 职业生涯规划。

### Java、C++、内存与网络

5. C++ 与 Java 在内存管理方面的区别。
6. C++ 是否有垃圾回收？
7. 对 GC 的理解。
8. 可达性分析适合使用什么数据结构？
9. 内存管理的策略和机制。
10. 垃圾回收算法。
11. 内存泄漏场景。
12. C++ 对象、类和对象内部类的存储方式。
13. 函数调用的实现机制。
14. 网络传输过程中做了哪些事情？
15. 如何保障网络传输的数据安全？
16. AES 的性能是否高于 RSA？
17. RSA 的实现原理。
18. MD5 加密后能否解密？
19. 网络传输中仅加密数据是否足以保证安全？还有哪些隐患？
20. 如何规避 DNS 劫持？
21. 如何规避洪泛攻击？
22. 如何把代码设计得更好、更健壮？
23. 常用设计原则和设计模式。

### 算法

24. 滑动窗口的最大值，返回值为 `List<Integer>`，需要注意边界条件。
25. 顺时针打印矩阵。
26. 最小路径和（原帖称未给样例，需要自行确定边界）。

## HR 面（17 分钟）

1. 前几轮面试结束后，对美团基本情况是否有了解？
2. 意向城市为上海的原因。
3. 追问简历上的实习经历及实习收获。
4. 对岗位的偏向。
5. 经历过最难的项目。
6. 手上的其他 offer 及选择方式。
7. 反问：入职后的部门和岗位是否需要自行选择、意向书发放时间。
