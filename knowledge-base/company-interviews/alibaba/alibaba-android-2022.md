# 阿里 Android 开发一、二、三面面经

[返回面经总览](../README.md) · [查看来源](../_sources.md)

> 来源：[2022-09-15 原帖](https://www.nowcoder.com/discuss/399686329112559616)
>
> 可信度：A（正文可核验） · 招聘类型：原帖未明确（Android 开发） · 招聘年份：未明确（发布时间：2022-09-15）

## 一面

1. Android 插件化。
2. 启动 Activity 的 Hook 方式。
3. `taskAffinity`。
4. OkHttp 是否支持 HTTP/2；HTTP/2 的功能。
5. TCP 拥塞控制。
6. TLS 握手及具体非对称加密算法。
7. `Handler` 的 `start(Runnable)`（原帖原文如此）如何实现；`Callback`、`Runnable`、`Message` 的执行优先级。
8. `Handler` 的阻塞如何实现，为什么不会阻塞主线程？
9. 求二叉树中两个节点之间的最大距离。
10. HTTP 状态码 206、未修改资源对应的状态码、302 和 301 的含义。
11. 多进程通信方式；Binder 的优势；AIDL 生成的 Java 类细节；多进程会遇到哪些问题？
12. 动态代理传入哪些参数？非接口类能否实现动态代理？
13. ASM 原理。
14. `Application` 和 `Activity` 在 Context 继承树上的区别及使用差异。
15. 任意一棵二叉树求最大节点距离。

## 二面

1. 设计一个日志系统。
2. 内存泄漏的分类及排查方法。
3. Touch 事件源码。
4. 组件化问题；`module` 和 `app` 的区别；模块间通信如何实现。
5. Native 崩溃日志采集及处理。
6. 用注解实现提示功能：当 `int` 值大于 3 时提示。

## 三面

1. Flutter 启动流程。
2. Flutter 与 Weex 的区别。
3. 组件化。
4. WebView 与 JavaScript 通信的手段。
5. `flutter_boost` 原理。
