# 阿里钉钉客户端 C++ 一面面经（2023）

> 来源：[2023-04-06 原帖](https://www.nowcoder.com/feed/main/detail/19b30b37791944f6a44bb5c0e657f103)
>
> 可信度：A · 招聘类型：钉钉音视频客户端实习 · 页面日期：2023-04-06

> 背景：本硕 9、非科班，项目为 WebServer 和 JSON 解析器。

## 一面（70 分钟）

1. `select`、`epoll`、`poll` 的区别。
2. `unordered_map` 的特性及其与 `map` 的区别。
3. 死锁的条件；只有一个互斥量和一个线程时是否会死锁？
4. 线程与进程的区别；线程资源的管理范围。
5. `extern` 与 `extern "C"` 的作用。
6. 静态库和动态库的区别，以及动态库的优劣。
7. HTTP 与 HTTPS 的区别；HTTPS 在什么情况下不安全。
8. TCP 与 UDP 的区别，哪个方向可能更大？
9. DNS 协议。
10. C++ 右值引用和完美转发。
11. Linux 与 Windows 编程的差异。
12. 面向对象编程与面向接口编程。
13. 中断机制。
14. JSON 解析器的实现效果。
15. MySQL InnoDB 的主要特性。

## 手撕

1. 手写 `memcpy`，考虑内存重叠。
2. 查找重复出现的数，未要求时间复杂度，可用排序。
