# 钉钉 Android 客户端一面面经（2024暑期实习）

> 来源：[2024-03-27 原帖](https://www.nowcoder.com/feed/main/detail/4987069fb95942c7aeac2e118053c897)
>
> 可信度：A · 招聘类型：暑期实习 · 发布日期：2024-03-27

## 一面（118分钟，电话面试）

### 操作系统

1. volatile 关键字的作用及原理
2. 为什么 volatile 不能实现原子性
3. 操作系统怎么进行内存管理
4. 分段和分页的区别
5. 操作系统如何实现线程的调度（从源码出发）
6. 线程和进程的区别

### 计算机网络

7. 输入 URL 到页面渲染的全过程（面试官插入追问：MAC 和 IP 的区别、为什么还需要 MAC、HTTP 请求报文格式）
8. HTTPS 的加密协议实现，具体加密算法，为什么用对称加密而非非对称加密
9. UDP 和 TCP 的差别，以及如何实现可靠的 UDP 协议（QUIC）
10. 安卓四大组件
11. Activity 生命周期

### 算法与数据结构

12. 合并 K 个有序链表（堆排序法、遍历求最大法、分治法两两合并）

### 项目经历

13. MVVM、MVP、MVC 设计模式的区别及各自优势
14. 实习经历深挖（为什么需要心跳检测，长连接场景下）
15. 项目深挖（面试官引导式提问）

### 反问

16. 面试表现反馈、如何更好表达项目、部门业务介绍
