# 阿里钉钉 Android 开发一、二、三面面经

[返回面经总览](../README.md) · [查看来源](../_sources.md)

> 来源：[2022-11-03 原帖](https://www.nowcoder.com/discuss/417774767388852224)
>
> 可信度：A（正文可核验） · 招聘类型：原帖未明确（正文为 Android 开发面试语境） · 招聘年份：未明确（发布时间：2022-11-03）

## 一面（80 分钟）

1. 自我介绍、项目介绍并展示架构图。
2. 因发展方向为音视频，追问使用过哪些现有框架。
3. 项目优化问题；MVC 到 MVP 的迁移；`Handler` 内存泄漏；MVP 与 MVVM 的理解。
4. 第三方库选型：`ObjectBox` 与 `greenDao` 的取舍、图片加载框架选择。
5. `HashMap` 和 `Hashtable`，以及 `ConcurrentHashMap` 的深入问题；Java 1.7 与 1.8 的区别；高并发下 `HashMap` 的问题。
6. Android 四大启动模式及对应场景。
7. `Handler` 机制；没有消息时 `IdleHandler` 的运行机制；为什么不能在子线程初始化？
8. 单例模式、使用场景（原帖举例 OkHttp 的 Session 存储）并现场编写。
9. 快速排序算法。
10. OkHttp 源码及整体架构流程图。
11. Android 四大组件的完整介绍和深入问题，包括 `IntentService`、`LocalBroadcast`。
12. 四大引用，并结合 MVP 框架回答。
13. HTTP 响应码，具体提到 200、404、500、304。
14. View 绘制流程；不使用 XML 如何实现居中定位？
15. 事件分发机制；如何实现单击和长按的判定？
16. 为什么使用 MQTT 协议；优势和原理。原帖作者说明自己只做过针对性压测并比较过 OceanLink 与 MQTT，未完整答出。

## 二面（30 分钟）

1. 自我介绍、优缺点和未来发展方向。
2. 项目整体介绍，以及如何实现分压。
3. 如果同时拿到阿里、腾讯、头条、谷歌 offer，如何选择（不考虑地域），并分析企业商业模式。
4. 对钉钉产品的理解；从其前身对标项目和后期商业模式分析钉钉的企业办公软件属性。
5. 钉钉 Mac 平台共享屏幕的 CPU 消耗问题。
6. 反问音视频方向的发展空间。

## 三面（60 分钟）

1. 自我介绍、项目介绍、项目优缺点对比。
2. MVC 与 MVP 的理解。
3. `Handler` 内存泄漏的具体原因和解决方案。
4. 空数据时 `Handler` 的阻塞问题；面试官建议继续阅读 `Looper` 源码。
5. 使用 MVP 的原因和优势；MVP 造成内存泄漏的场景。
6. HTTP 长连接和短连接；HTTP 三个版本的主要区别。
7. 从输入域名到页面完成请求的全过程：DNS、TCP 三次握手、四次挥手、IP 路由、链路层和物理层。
8. `RecyclerView` 复用机制及与 `ListView` 的区别。
9. `HashMap`、`ConcurrentHashMap`、`Hashtable` 的数据结构和线程安全；Java 1.7 与 1.8 的区别。
10. App 冷启动、热启动流程；AMS、初始化和 Activity 生命周期。
11. 算法：三数之和，原帖作者最终采用 `O(n^2)` 解法。
