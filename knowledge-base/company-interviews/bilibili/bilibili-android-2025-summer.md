## Android / 客户端基础

1. Android View 绘制流程。
2. 父 View 对子 View 的三种约束。
3. `UNSPECIFIED` 未指定约束的应用场景。
4. Handler 的运行机制。
5. Looper 和 Handler 的关系，一对多还是一对一？
6. Handler 处理消息的类型。
7. 什么情况下会产生 ANR？
8. 什么是内存泄漏？
9. Handler 引用 Activity 时，Activity 是否一直不会被释放？
10. Handler 为什么会持有 Activity？
11. 常用的 Git/SVN 操作。
12. HTTP 请求从头到尾的过程。
13. JSON 序列化和反序列化的原理。
14. Android 打包流程。
