# 字节抖音直播客户端一、二面面经

> 来源：[2024-10-14 原帖](https://www.nowcoder.com/discuss/668858134533779456)
>
> 质量：A（个人原帖，两轮正文完整可核验） · 招聘岗位：抖音直播客户端 · 招聘类型：客户端转岗/校招语境，届次未明确 · 发布日期：2024-10-14

## 一面

### Java、JVM 与并发

1. 面向对象的封装、继承、多态，并结合项目说明多态。
2. 接口和抽象类的区别。
3. 类加载机制。
4. 泛型解决的问题、上下界和类型擦除。
5. `ArrayList` 与 `LinkedList` 的区别。
6. `HashMap` 底层实现、红黑树和哈希冲突处理。
7. `LinkedHashMap` 的底层实现及双向链表的作用。
8. `Hashtable` 与 `ConcurrentHashMap` 的区别。
9. 线程池参数及核心线程数如何根据任务类型设置。
10. `synchronized` 是否可重入、如何实现、锁升级。
11. JVM 内存结构与 GC：回收对象判定、垃圾回收算法和回收器。
12. 老年代算法；标记清除与停顿复制的优缺点和内存效率。

### 操作系统与网络

13. 进程和线程的区别。
14. 线程间通信；信号量属于哪种同步方式，是否还有主动通信方式。
15. `volatile` 解决什么问题。
16. 操作系统如何保证 CAS 操作的原子性。
17. HTTP 状态码。
18. HTTP 与 HTTPS 的区别。
19. TCP、IP 所在层次；三次握手、四次挥手能否少一次。
20. TCP 滑动窗口。
21. TLS 握手过程及使用的加密算法。
22. 从输入网址到出现网页的过程。

### 算法

23. 找到数组中右边第一个比当前元素大的数的下标，单调栈。

## 二面

1. Kotlin、鸿蒙接触情况。
2. 继承与组合的区别及适用场景。
3. `HashSet`、`HashMap` 的底层实现，红黑树是否还有优化空间。
4. 排序算法；快排是否最快以及何时最快。
5. 线程、进程、共享资源并发安全和死锁。
6. GC 时进程中线程的状态及原因。
7. 设计模式，代理模式的使用场景。
8. TCP 与 UDP、HTTP 基于哪种协议、QUIC 的使用原因。
9. HTTP/HTTPS 安全性、证书泄露风险。
10. 客户端加载图片时如何提升效率。
11. 算法：合并有序数组。
