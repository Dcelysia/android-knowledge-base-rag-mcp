# 字节剪映/抖音客户端 C++ 面经（2024）

>
> 质量：A · 招聘岗位：剪映/抖音客户端，C++/音视频，Android 与 PC · 招聘类型：校招/社招语境未明确 · 发布日期：2024-11-12

## 剪映/抖音测开一面（90 分钟）

- 视频播放器设计、歌词与画面同步、内存泄漏、逆向工程和 Android 软件。
- H.265/H.264、编解码与封装格式、OpenGL/OpenCV。
- 视频黑屏/花屏检测、抖音 OOM 排查、播放器埋点、不同硬件码率适配。
- 纯虚函数与虚函数、多态、URL 到页面显示、智能指针。

### 算法

- 合并有序数组。

## 剪映/抖音测开二面（40 分钟）

- 最长无重复子串、反转链表。
- 安全实习业务、Dex 解析、逆向工作、测试理解和开发能力。

## 剪映 C++ 客户端一面（60 分钟）

- TCP/IP、TCP/UDP、H.264/H.265、编解码、进程线程、同步多线程、select/poll/epoll。
- C++ `const`、引用与指针、`new`/`malloc`、多态。
- 实习项目、音视频同步。

### 算法

- 删除倒数第 K 个节点，关注边界条件。

## 剪映 C++ 客户端二面（50 分钟）

- Qt 跨平台原理及与 Windows 的通信。
- APK/Dex 解析、Dex 体积、歌词逐字同步。
- 播放效果衡量、播放器性能优化、YUV/RGB、OpenCV 亮度调整。
- RTSP/HLS 差异、直播协议选择、RTSP 服务器。

### 场景题

- 让图片中的所有点随机变黑，讨论如何保证最终全部完成。
