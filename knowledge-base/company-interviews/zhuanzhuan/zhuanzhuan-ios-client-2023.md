# 转转 iOS 客户端开发面经（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/486048919542059008)

> 可信度：A · 招聘类型：iOS 客户端开发 · 发布日期：2023-06-09

> 质量说明：原帖是多家公司客户端面试汇总，以下仅提取其中明确标注“转转 iOS 开发岗位”的题目。

## 转转 iOS 开发岗位

1. iOS 网络请求如何处理。
2. HTTP 是否有状态，以及如何解决无状态。
3. Web 如何判断用户是否登录，Cookie 及其加密机制。
4. iOS 文本输入控件：`UITextField`、`UITextView`。
5. iOS 列表滑动与 `UITableView` 卡顿原因、优化方式。
6. iOS GCD。
7. Objective-C Block、用法和回调方式。
8. iOS 内存管理：ARC、MRC。
9. Objective-C 属性 `strong`、`weak`、`copy`、`assign` 的区别。
10. `copy` 与 `mutableCopy` 的区别。
11. 从 `new`、`alloc` 角度说明堆和栈的区别。
12. 判断链表是否有环。
13. `static`、`const` 和 `define` 的区别。
14. HTTP 与 HTTPS 的区别。
15. Charles 为什么能看到 HTTPS 请求。
16. MVC 与 MVVM，以及 MVVM 的优点。
17. iOS 数据保存到本地的方法。
