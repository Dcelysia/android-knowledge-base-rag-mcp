# OPPO 系统工程师提前批面经（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/527229289750593536)
>
> 可信度：A · 招聘类型：终端系统工程师校招提前批 · 面试日期：2023-08-18、2023-08-28、2023-08-29 · 发布日期：2023-09-07

## 一面

1. 项目中的 Code Review、代码保存位置和合并代码出错后的调试方式。
2. 手机厂商和手机操作系统；Android 底层系统。
3. Android 系统架构和 Java 阅读能力。
4. C++、操作系统基础，包括虚函数、进程与线程。

## 二面

1. 项目中的高性能网络技术、项目背景和个人负责程度。
2. Linux 内存管理和文件系统。
3. 为什么选择 OPPO、不去互联网，以及部门工作内容。

## HR 面

1. 家庭情况、择业关注点和加入 OPPO 的原因。
2. 预期薪资、工作地点、压力排解和项目困难阶段。

> 原帖记录职位为系统工程师，工作方向包括手机内存优化和文件系统；按终端系统校招提前批归档，不标为纯 Android 应用开发。
