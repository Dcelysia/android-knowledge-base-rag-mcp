# 华为南研所终端线下面经（2023 秋招）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/540850679087132672)
>
> 可信度：A · 招聘类型：华为终端软件/C++/鸿蒙 · 面试日期：2023-09-27

## 面试题

### 一面

1. C++ 链接时符号冲突、动态链接与静态链接。
2. `vector` 扩容机制。
3. `new/delete` 与 `malloc/free`。
4. 堆栈区别；C++/Java 内存机制及各段内容。
5. 如何避免重复引用头文件。
6. 拷贝构造函数的使用时机。
7. 手撕 LeetCode 210（课程表 II）。

### 二面与主管面

1. 深挖华为实习、鸿蒙理解、实习困难和需求改进。
2. 项目需求完整周期及用户调研/对接。
3. 手撕 LeetCode 487（最大连续 1 的个数 II）。
4. 系统调用入口、单片机启动、内核上下文切换、内存生长方向和生命周期。
