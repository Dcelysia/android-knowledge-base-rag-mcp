# 腾讯 PCG 架构部门移动客户端一面（2024）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/9c1fff5f5e674a1c9fcc4d75e5c1c42d)
>
> 可信度：A- · 招聘类型：移动客户端/C++ 客户端，非纯 Android · 面试日期：2024-03-21

## 面试题

### C++

1. `new/delete` 与 `malloc/free` 的联系和区别；`delete[]`。
2. 对象大小、`class` 与 `struct`、全局变量与局部变量、指针大小。
3. 智能指针；虚函数、纯虚函数和多态。
4. 递归与循环及时间/空间复杂度。
5. 指针参数与引用参数。
6. 哈希冲突处理（链地址法、开放地址法）。
7. C++ 内存分区、链表与数组、类型萃取、`NULL` 与 `nullptr`。
8. 大数组找重复元素；数据无法一次装入内存时如何处理。

### 操作系统与网络

1. 进程/线程、线程调度开销、并发/并行、进程间通信、同步/互斥、虚拟内存。
2. 网络分层、HTTP/HTTPS、HTTPS 通信过程、TCP/UDP、TCP 可靠性、流控与拥塞控制、HTTP 状态码。

### 编程

1. 非递归实现快速排序。
2. 找到字符串中至少出现两次且长度最大的子串，例如 `banana` 输出 `ana`。
