# OPPO 系统工程师提前批（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/527229289750593536)
>
> 可信度：B · 招聘类型：系统工程师提前批，Android/Linux/C++ · 面试日期：一面 2023-08-18，二面 2023-08-28，HR 2023-08-29

## 面试题

### 一面

1. 项目 Code Review、代码保存位置、合并代码出错如何调试。
2. 手机厂商和手机操作系统；Android 底层系统。
3. Android 系统架构、Java 阅读能力。
4. C++/操作系统基础，包括虚函数、进程与线程。

### 二面

1. 项目中的高性能网络技术、项目背景和负责程度。
2. Linux 内存管理和文件系统。
3. 为什么选择 OPPO、不去互联网；部门工作内容（手机内存优化、文件系统）。

### HR 面

1. 家庭情况、择业看重什么、为什么加入 OPPO。
2. 预期薪资、地点、压力排解、项目中最困难的阶段。

> 原帖岗位偏系统而非 Android 应用开发，保留其终端/系统价值但不标为纯 Android。
