# 华为 OD 流程记录（含 Android/客户端，2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/467292691047399424)
>
> 可信度：B · 招聘类型：华为 OD，Java/Android/客户端交叉 · 面试日期：一面/HR/二面 2023-03-20，主管面 2023-03-21

## 面试题

### 一面

1. Java Map 的实现、原理和区别；ArrayList 与 LinkedList。
2. 线程创建、异常处理、Java 版本、GC 时机与方式。
3. 内存泄漏/溢出、Java 锁、设计模式、文件读写、MVC、Java 框架、常见异常、红黑树。
4. 手撕：按字符出现频率降序排列字符串。

### 二面

1. Android、客户端与服务器交互相关项目八股。
2. 手撕 LeetCode 17.16“按摩师”。

### 其他流程

- OD 机试、性格测试、HR 面和主管面；HR 询问学习、成就、缺点、团队协作、工作环境和华为精神。

> 这是 OD 流程记录，原帖明确有机试和大量 Java/通用题，Android 题只占一部分，按 B 级保存。
