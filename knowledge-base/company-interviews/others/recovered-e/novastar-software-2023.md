## 面试题

1. 写文档有哪些好处和坏处。
2. 项目带来哪些帮助；项目在技术上解决过的最大问题。
3. 项目使用的算法可以解决哪一类问题。
4. Java 如何进行内存管理。
5. 垃圾回收为什么设计新生代和老年代。
6. 操作系统如何进行内存管理、如何进行优化。
7. TCP 有哪些状态；`TIME_WAIT` 过多如何解决。
8. HTTPS 与 HTTP 的区别；HTTPS 客户端与服务器的通信过程。
9. 了解哪些设计模式，如何使用。
10. 无手撕；最后反问。
