# 作业帮 C++ 音视频开发面经（2024）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/f1225b39fa4e41c19c7a2afc58da50aa)

> 可信度：A · 招聘类型：C++ 音视频/客户端开发 · 面试时间：2024-09-26、2024-10-16 · 发布日期：2024-12-16

## 一面

1. `const`、C++ 多态、右值引用及其性能收益。
2. 如何防止内存泄漏，以及智能指针的类型。
3. `map` 与 `unordered_map` 的差别和选型。
4. 多进程与多线程的使用、线程调度和线程安全。
5. 锁、信号量与 `mutex` 的区别及使用方式。
6. 子进程是否会修改父进程的值。
7. OS 内存管理和 `mmap` 涉及的内存管理。
8. 主机之间应用层数据传输流程，UDP 缓冲区和 TCP 缓冲区的作用。
9. IO 复用、`select` 与 `epoll` 的区别及 `epoll` 的性能问题。
10. 查找数组中 K 个最大值。
11. 手撕可能带环的两个链表的相交节点。

## 二面

1. C++ 多态、父子类设计，以及组合优于继承的理解。
2. 虚析构函数、析构顺序、C++11 新特性和智能指针线程安全。
3. Lambda、右值引用、`emplace_back`。
4. 多进程、多线程、生产者消费者和 `condition_variable`。
5. 内存分配注意事项和内存泄漏防止。
6. 客户端闪退的处理方式及未来发展规划。

> 原帖还记录了 2024-11-05 HR 面和 2024-12-16 OC；岗位是 C++ 音视频/客户端方向，不归入 Android 专项条目。
