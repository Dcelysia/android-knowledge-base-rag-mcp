# 作业帮直播课移动端面经（2025一二面）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/ac58533622c14ebdaf3784fe424798aa)

> 可信度：A · 招聘类型：直播课移动端（C++/客户端方向）· 面试时间：2025-06-30、2025-07-07 · 发布日期：2025-07-07

## 一面

1. C++ 智能指针。
2. 线程与进程的区别。
3. TCP 与 UDP 的区别。
4. 链表与数组的区别。
5. 多并发的优点、缺点和使用场景。
6. 工厂模式中熟悉的模式、使用场景、实现方式和优缺点。
7. C++ 通过什么进行封装，以及封装的优点。
8. 实际场景中线程如何访问共享资源。
9. 手撕最长回文子串。

## 二面

1. 讲述项目经历及部署过程。
2. 群聊和单聊的底层区别。
3. UDP 和 TCP 的主要区别。
4. 聊天信息如何保存，以及异地登录后如何获取历史记录。
5. 10GB 文件如何上传，如何进行分片上传。
6. 分片位于哪一层，以及计算机网络七层逻辑结构和底层原理。
7. MySQL 索引的作用和实现。
8. 手撕线程安全的单例模式，并说明单例模式的理解。

> 原帖公开记录的题目主要围绕 C++、网络和客户端业务；岗位原文为“直播课的移动端”，未将其改写为 Android 专项面经。
