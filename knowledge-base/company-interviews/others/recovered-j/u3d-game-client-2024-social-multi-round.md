## 原帖公开正文

前言：记录下自己面试的经验，因为自己从其他同学的面经中受益良多，现在也想记录一下。

已经面试完了，最终选择了网易。挂了或者拒绝了：完美世界手游、盛趣、MetaApp、吉比特、途游、友塔、网易外包、大梦龙途、完美世界诛仙 1、飞鱼科技、冰川网络、小牛互联、域起网络、微派手游、凉屋游戏等。最终 offer：网易。

以下问题是多家公司面试内容的汇总，原帖未标注具体公司。

### 一

1. C# 和 C++ 的类的区别。
2. C# `List` 添加 100 个 `object` 和 100 个 `int` 时内存如何变化。
3. 重载和重写的区别，重载是怎么实现的。
4. 重写是怎么实现的；子类继承父类虚函数的实现过程、虚函数表和指针。
5. 虚函数表是类的还是对象的。
6. 用过哪些 C++ STL。
7. `vector` 底层如何实现。
8. `vector` 连续添加 100 次数据时内存如何变化。
9. `map` 底层、红黑树查询和插入的时间复杂度，`unordered_map` 的底层实现。
10. `list` 底层如何实现，队列如何实现。
11. 设计 6 个玩家进行 3v3 贪吃蛇的游戏场景：水果使蛇变长，蛇碰到队友或自己的尾巴无事，碰到对手尾巴死亡；如何抽象成代码。
12. 简历中游戏 UI 优化的具体做法。
13. 为什么使用图集，规定图集大小，超出图集大小怎么办。
14. 什么情况下 draw call 会被打断，是否了解渲染。
15. RPG MMO 项目服务器代码如何实现，有多少进程和线程，进程之间如何通信。
16. TCP/UDP 位于哪一层，socket 是什么。
17. C++ 和 Lua 如何通信。
18. C++ 和 C# 的异同。
19. 九宫格原理，如何让一张很小的图变大。
20. 面向对象设计。
21. 项目中做了哪些 UI 系统，项目 UI 框架如何交互。
22. 资源更新：大图集只更新一张图时如何更好地更新。
23. Python GC；作者说明只了解 Lua GC。
24. C# 中 `ref` 和 `out` 的区别。
25. 手写快排。
26. 如何优化 UI、过大的图集、Spine、特效和 animation。
27. TCP 三次握手和四次挥手。

### 二

1. 3D 模型怎么显示到 2D UI 上。
2. C# `ArrayList` 和 `List` 的区别。
3. 接口和抽象类的区别，什么时候使用接口。
4. UGUI 如何渲染 UI，UGUI 的层级管理，如何不打断合批，合批流程。
5. 观察者模式。
6. 项目 UI 框架如何管理 UI 切换和场景切换。
7. Unity 和 Android 如何交互。
8. Unity 编辑器扩展，新增窗口继承哪个类。
9. Lua 类型，`pairs` 和 `ipairs` 的区别，Lua 如何实现面向对象，`__newindex` 的用途。
10. 对象池的使用、优点和缺点。
11. Unity 协程和线程的区别，项目中协程的使用。
12. Unity 中判断两个物体碰撞的条件，碰撞器和触发器的区别。
13. A* 如何实现，关键数据结构，A* 是广度还是深度搜索，搜索路径是最短还是最优。
14. 项目动画的制作方式及参与情况。
15. Lua 交互，xlua。
16. 上个项目的具体内容。

### 三

1. 项目设置系统如何实现。
2. 做过哪些 UI 系统。
3. 用协程做 UI 系统是否会出现同步不及时的问题。
4. 是否使用 UGUI，项目 UI 框架如何实现。
5. 是否修改过 UGUI 源码，了解哪些改动。
6. 滑动窗口如何定向滑到指定位置。
7. UI 是否使用粒子特效。
8. 窗口动效如何实现。
9. UGUI 如何优化。
10. 除图集材质外是否使用其他材质。
11. UGUI `Mask` 原理，为什么会打断合批，如何实现不打断合批的 Mask。
12. Lua `metatable` 在项目中的使用。
13. Lua 面向对象继承的实现及遇到的问题。
14. Lua 全局变量和常量的使用。
15. C# 和 Lua 如何交互。
16. Lua 内存优化，UI 框架如何控制 GC 时机。
17. Unity Profiler 检查出过哪些问题。
18. 游戏中的公共组件。
19. 战斗相关开发，技能模型和动效。
20. 接入过哪些 SDK，如何打包。
21. 职业规划。

### 四至七

原帖还记录了若干公司面试中的问题：

- C++ 中 `delete` 和 `free` 的区别、堆和栈、指针和引用、多态、不可继承类、Socket、TCP/UDP、多线程通信与死锁。
- Lua 与 C++ 绑定、计算机图形学、开发工具、数据持久化、对象池、图片淡出、灰度显示 Shader、协程和延时器。
- STL 中 `list`、`vector`、`map`、`unordered_map` 的区别，`map` 删除元素时 `erase` 返回迭代器的含义，`vector` 扩容，容器选择。
- Lua 面向对象、`__newindex`、点号与冒号调用、异常捕获、闭包；C# `ArrayList`/`List`、字典、栈和队列、链表和数组复杂度、二叉树和平衡二叉树、Dijkstra 和 A*、排序算法、协程和线程。
- 资源包管理和加载、TCP 拆包粘包、draw call、合批、静态合批的问题、xlua 与 C# 交互、C# 在 Unity 中的编译运行流程、Mono 内存、Unity GC。

### 八

1. Lua 如何实现面向对象。
2. `_newIndex` 的作用。
3. 点号和冒号调用的区别。
4. Lua 异常捕获和堆栈打印。
5. 闭包概念并举例。
6. C# `ArrayList` 和 `List` 的区别，`Dictionary` 如何实现，栈和队列的特点。
7. 链表和数组的插入、删除、访问复杂度。
8. 二叉树和平衡二叉树。
9. Dijkstra 和 A* 算法。
10. 常用排序算法，快排和堆排。
11. 协程和线程，项目组使用 ECS 后需要学习的内容。
12. 资源包管理和加载。
13. TCP 三次握手和四次挥手，拆包粘包及解决方法。
14. draw call、合批，静态合批过多的问题。
15. xlua 和 C# 交互原理。
16. C# 代码在 Unity 中的编译运行流程。
17. Mono 内存特点、对象内存释放和 Unity GC 流程。

### 九

1. 100 万玩家的排行榜如何取前 100 名。
2. 建堆的算法复杂度，玩家发生变更时如何调整排名。
3. 二分查找复杂度。
4. C# `Dictionary` 如何实现。
5. Hash 表查询和插入的时间复杂度，Hash 冲突的解决方式。
6. 开放定址法线性探测删除元素时的问题和时间复杂度。
7. 是否做过图集多引用检查工具。
8. Unity 产生 GC 的原因，如何减少 GC。
9. 设计模式及 UGUI 源码、布局组件和 `LayoutElement`。

总结和建议：最好在项目中呆满三年，多学习核心技术；社招面试中经验和优势点很重要。基础很重要，对自己设计的框架或系统最好画图讲解。
