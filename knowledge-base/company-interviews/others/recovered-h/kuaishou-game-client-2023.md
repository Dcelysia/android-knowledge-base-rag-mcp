# 快手游戏客户端秋招一二面（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/524264232146296832)
>
> 可信度：A · 招聘类型：游戏客户端秋招 · 页面发布日期：2023-08-24

## 一面

1. 实习与项目；C++ 面向对象、多态、虚函数及底层原理。
2. STL、`vector`/`list`、`map`/`unordered_map` 底层、哈希冲突、红黑树。
3. 智能指针、`shared_ptr` 循环引用、`weak_ptr`；树 DFS/BFS 迭代实现；队列与栈。
4. 动态链接与静态链接；TCP/UDP 及 TCP 可靠机制。
5. 人脉网（并查集/图 BFS）、搜索联想（字典树）、游戏项目；手撕牌型检测。

## 二面

1. C++ 多继承、虚函数表位置、菱形继承、虚继承。
2. `static` 初始化时间、`const` 存储位置与初始化时间。
3. 读小文件/大文件的方式、`mmap` 及小文件不使用 `mmap` 的原因。
4. `malloc` 大内存的底层实现；虚拟/物理内存、缺页中断。
5. `unique_ptr`/`shared_ptr`；进程通信、共享内存与消息队列场景。
6. TCP/UDP 场景、UDP 可靠传输及丢包延迟处理；手撕游戏状态机。
