# OPPO 系统工程师面经（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/527229289750593536)
>
> 可信度：A · 招聘类型：系统工程师提前批，Android/Linux/Java Framework 方向 · 页面发布日期：2023-09-07

## 一面

1. 自我介绍与项目介绍；Code Review、代码保存位置、合并代码出错后的调试方法。
2. 手机厂商与手机操作系统；Android 底层系统与 Android 架构。
3. Java 能否读写；C++、操作系统、虚函数、进程与线程。
4. 加班态度与工作方向。

## 二面

1. 项目中的高性能网络技术、是否主要负责人、项目背景。
2. 科研项目与前后端项目的技术栈和亮点。
3. Linux 内存管理与文件系统。
4. 为什么选择 OPPO；部门工作地点与手机内存优化、文件系统相关工作。

## HR 面

1. 家庭情况、求职关注点、对 OPPO 的了解、期望薪资与工作地点。
2. 读研压力与排解方式；项目不同阶段的困难；长期保持的习惯。
