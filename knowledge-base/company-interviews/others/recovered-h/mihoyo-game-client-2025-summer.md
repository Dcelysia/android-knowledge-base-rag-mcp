# 米哈游游戏客户端暑期实习一二面（2025）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/5813ecf9a23a4915ba75b768481bb00d)
>
> 可信度：A- · 招聘类型：游戏客户端暑期实习 · 页面日期：05-21（牛客页面仅显示月日）

## 一面

1. 十二个球中一个更重时用天平找出；十三个球；一个重量不确定时的最少次数。
2. GAS；A* 是否一定得到最优路径及如何保证。
3. UE GC 底层实现、缺点；对象池实现、缺点与优化。
4. `static` 用法；虚函数、虚析构、构造/析构中调用虚函数；静态多态。
5. 函数重载返回值；智能指针、弱引用计数、`unique_ptr` 转移。
6. `map` 与 `unordered_map`；红黑树与哈希的实现和选型。
7. 进程/线程、线程不安全与解决方式、32/64 位系统。
8. 手撕跳台阶、接雨水。

## 二面

1. C 风格数组实现可扩容队列。
2. 多线程并发队列能否不用锁、如何用原子变量实现无锁队列。
3. 内存分页、TLB、多级缓存、原子变量原理。
4. `lock_guard` 如何在函数结束自动解锁，以及如何实现类似的资源自动释放。
5. UE 网络通信、UDP 可靠性与丢包重发。
