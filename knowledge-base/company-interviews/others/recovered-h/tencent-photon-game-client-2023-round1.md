# 腾讯光子游戏客户端秋招一面（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/528972800200032256)
>
> 可信度：A · 招聘类型：游戏客户端秋招一面 · 页面发布日期：2023-09-06

## 公开题目

1. Unity 与 UE 的区别：Gameplay 框架、引擎底层、动画系统、AI、物理引擎、碰撞检测。
2. 状态机与行为树。
3. C++ 虚函数、虚函数表生成时机、虚函数表指针位置、C++ 异常、C++11 新特性（`auto`、`friend`）。
4. `sizeof` 基础类型、虚函数类与非虚函数类；内存对齐及原因。
5. 线程间通信、哈夫曼编码。
6. 四元数与欧拉角、万向节死锁。
7. Phong 与 Blinn-Phong；渲染管线可编程部分。
8. 判断点在三角形内、判断两个矩形相交。
9. 算法：最大子序列和、最长回文子串。
