# 阿里钉钉音视频客户端 C++ 面经（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/19b30b37791944f6a44bb5c0e657f103)
>
> 可信度：A · 招聘类型：客户端 C++/音视频实习语境 · 页面发布日期：2023-04-06

## 一面公开题目

1. `select`、`poll`、`epoll` 的区别。
2. `unordered_map` 与 `map` 的特性和区别；死锁条件；单互斥量与单线程是否会死锁。
3. 线程与进程、线程资源管理范围。
4. `extern`、`extern "C"`；静态库与动态库及优劣。
5. HTTP/HTTPS、HTTPS 的中间人攻击风险、TCP/UDP、DNS。
6. C++ 右值引用、完美转发；Linux 与 Windows 编程差异；面向对象与面向接口。
7. 中断机制、JSON 解析器实现、InnoDB 特性。
8. 手撕 `memcpy`（考虑内存重叠）；找重复出现的数。

## 其他轮次公开线索

1. JSON 解析器为什么使用 `variant`。
2. 无自定义方法的类会生成哪些方法。
3. 为什么选择钉钉音视频客户端、专业与经历等常规问题。
