## 公开题目

1. C++、网络与操作系统：虚拟内存、智能指针、TCP 三次握手/四次挥手、单向链表、栈与队列、指针与引用、内存管理。
2. iOS 常用三方库（图片、视频、JSON 解析）；RunLoop。
3. 多线程、GCD、同步/异步实现、Crash 场景、循环引用。
4. Git 与 SourceTree；CocoaPods 基于什么实现；若用 Python 解析 Podfile 工具如何设计。
5. 手撕环形链表；重新排列数组，使顺序输出后组成的数字最大。
