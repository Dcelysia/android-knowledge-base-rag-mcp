# 腾讯光子游戏客户端面经（2024）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/664200375213338624)
>
> 可信度：A · 招聘类型：游戏客户端秋招语境 · 页面发布日期：2024-09-14

## 公开题目

### 引擎与图形学

1. 实习内容、Demo 转为联网如何做、骨骼动画、蒙皮、动画重定向。
2. Mesh 中存储哪些内容；渲染一个物体的过程。
3. 模板测试、Alpha 测试、顶点/片元着色器、不透明与透明物体的渲染顺序。
4. 阴影、贴图大小、世界坐标到屏幕坐标、MipMap、过大贴图放到小分辨率上的影响。
5. Draw Call、合批、图集、静态合批、动态合批及 Mesh 合批规则。
6. 判断点是否在平面内；Unity 粒子系统流程；资源内存占用如何定位。
7. UE Gameplay、ECS、UE GAS、技能释放流程、Ability/Effect 配置、Buff 过滤与阻挡。
8. UI 框架与 UI 操作流程、Shader 变体优化与加载流程、Memory Profiler、UE PSO。
9. Unity 生命周期、物理与渲染时机、行为树节点、A* 寻路与 NavMesh。

### 网络、C++/C# 与系统

1. TCP 三次握手；网络同步、帧同步、状态同步；回滚拉扯如何处理。
2. DS、Unity 中实现 DS、RPC 调用过程、复制发生了什么及哪些内容需要复制。
3. 虚函数、虚表位置及能否修改；构造/析构函数；移动构造、左右值、完美转发、模板特化。
4. 智能指针、迭代器失效、`const` 引用；装箱与拆箱；锁、原子操作、协程与线程、`foreach` 原理、大端小端。
5. 究极手和物理系统如何配合、攀爬碰撞体性能、World Streaming。

## 个人与项目

1. 为什么不读研、为什么不转正、为什么一直使用 Unity、能否提前实习。
2. 项目涉及 Shader 变体优化、加载优化、引擎源码修改、技能框架和帧同步。
