# 腾讯光子游戏客户端面经（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/478555253038678016)
>
> 可信度：A · 招聘类型：游戏客户端，届次未明确 · 页面发布日期：2023-04-21

## 一面

1. 自我介绍；如何学习 C++、看过哪些书；为什么做游戏客户端。
2. 对象内存结构需要考虑什么：虚函数、虚基类、字节对齐、继承体系。
3. 字节对齐、32/64 位数据大小、位域、构造函数/析构函数中调用虚函数、析构函数为什么应为虚函数。
4. `set`/`map` 底层、红黑树及其与 AVL 的区别、哈希冲突处理、内联函数与内联时机。
5. 手撕最长不重复子串，讲解滑动窗口和哈希去重。
6. 渲染管线搭建与优化、批处理减少 Draw Call、事件系统、日志系统和日志 I/O 多线程处理。
7. 目前所在城市与意向城市；反问 UE/Unity 趋势、学习路线及工作中引擎使用情况。
