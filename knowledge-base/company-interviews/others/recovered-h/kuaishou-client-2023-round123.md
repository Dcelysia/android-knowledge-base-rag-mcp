# 快手客户端一二三面经（2023）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/544176659033792512)
>
> 可信度：A · 招聘类型：客户端校招语境，届次未明确 · 页面发布日期：2023-10-18

## 一面

1. C++ 程序内存分布、堆栈区别、野指针与内存对齐。
2. 结构体指针参数与普通传参的取舍。
3. TCP 可靠传输、三次握手中各次握手丢失时的行为、GET/POST、滑动窗口。
4. 项目复杂后如何重新设计、策略模式；手撕只能在栈上/堆上实例化的类。

## 二面

1. 项目数据一致性、文件删除策略与边界问题。
2. 封装/继承/多态的实际使用，如何判断新类是否需要继承。
3. 数组与链表、栈与队列；用栈实现队列、用队列实现栈。
4. 哈希本质；如何设计同时支持随机访问和较快插入删除的结构。
5. HTTPS 相比 HTTP 的改进、客户端与服务端的考虑、RPC 与 HTTP。
6. 时间复杂度、冒泡与快排；手撕两个生产者一个消费者模型。

## 三面

1. 项目整体与一致性；若做监控需要哪些指标。
2. 手撕字符串相加；反问业务与后续流程。
