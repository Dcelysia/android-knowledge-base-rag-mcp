# 快手安卓客户端面经（2023 社招语境）

> 来源：[牛客原帖](https://www.nowcoder.com/discuss/529062641008918528)
>
> 可信度：A · 招聘类型：Android 客户端社招语境 · 页面发布日期：2023-09-07

## 一面

1. JVM 内存模型、内存区域用途、线程共享区域、方法区线程共享原因、OOM 区域。
2. 垃圾识别与回收算法、GC Root、垃圾收集器分类与并行收集器原理。
3. 类/对象加载过程、双亲委派、好处、自定义类加载器及生产使用。
4. 动态代理实现与原理、AOP 的其他实现、字节码插装方式。
5. 注解作用、分类、元注解；Java 多线程本质、`volatile` 使用场景、线程池与拒绝策略、线程生命周期。
6. 手撕从 `n` 到 `m` 的链表反转。

## 二面

1. 数据库三范式、分页查询 SQL。
2. 双重检查锁单例及双重检查原因。
3. View 绘制流程、自定义 View 实现动画；`invalidate` 与 `requestLayout`。
4. View 事件分发；子 View 的 `onTouch` 返回 `true` 后是否继续分发。
5. 手撕二叉树深度。
