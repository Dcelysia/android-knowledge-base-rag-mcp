## 一面

1. 自我介绍和项目介绍。
2. MVC、MVVM；Android 四大组件。
3. 两种序列化方式。
4. 自定义 View；常用 UI 组件；ListView 的缓存和复用。
5. Activity 切换与生命周期变化。
6. Handler 的使用场景；分页如何实现。
7. SQLite 索引和数据库创建。
8. 线程池、进程同步、synchronized。
9. 内存泄漏和 Java 引用类型。
10. Activity 四种启动模式，singleTop 与 singleInstance 的区别。
11. OkHttp 与拦截器。
12. 无手撕，反问如流业务；约半小时后收到二面通知。

## 二面

1. 自我介绍和项目介绍。
2. 控制反转。
3. 技术栈交流；Flutter 的看法以及为什么没有深入学习。
4. 计算机网络，代码题：用 Kotlin/Java 写单例、最长公共子序列。
