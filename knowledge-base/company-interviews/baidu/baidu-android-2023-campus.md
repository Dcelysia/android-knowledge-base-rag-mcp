## 一面

1. 进程与线程、线程池及 Java 线程池类型。
2. OOM 与内存泄漏的区别和联系。
3. Java GC、软引用与弱引用。
4. Activity 与 Fragment 生命周期。
5. Handler 机制；Handler、Looper、MessageQueue 的对应关系。
6. Android 进程间通信方式。
7. ConstraintLayout 与 RelativeLayout 的区别。
8. dp、px、dpi 的区别与联系。
9. OSI 七层模型、TCP/IP/UDP 所属层次及差异。
10. 手撕：忽略非字母数字判断回文串；O(1) 空间合并两个升序链表。
