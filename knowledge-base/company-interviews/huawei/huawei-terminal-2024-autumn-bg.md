# 华为终端 BG 软件开发面经（2024 秋招）

> 来源：[牛客原帖](https://www.nowcoder.com/feed/main/detail/23a3c4cd52904047abad49e3d0d389cf)
>
> 可信度：A · 招聘类型：终端 BG 软件开发秋招时间线 · 发布日期：2024-10-17

## 第一轮技术面

1. 回顾笔试第二题“放田字方块”的解题思路。
2. 手撕全排列。
3. 深挖在 B 站实习期间的项目思路。
4. Java 内存泄漏及常见场景：静态集合类、连接资源未关闭、`ThreadLocal`。
5. Java 多线程同步方式，以及 `synchronized` 与 `ReentrantLock`。
6. `synchronized` 的使用方式。
7. 设计模式：单例、工厂、观察者、策略及设计理念。

## 第二轮技术面

1. 在校成绩、研究生项目和课题。
2. 优化类项目的一般方法，以及具体项目中的落地过程。
3. 手撕两个字符串的子串判断，使用双指针。

## 线下主管面

1. 实习和科研中的困难及应对方案。
2. B 站实习的最大收获和可改进之处。
3. 对加班和华为企业文化的看法。
