## 一面

1. 什么时候开始接触 Android。
2. Java 类成员访问权限从小到大；默认访问权限是什么。
3. Java 四种引用类型；char、int、float 分别占几个字节。
4. Service 的作用；耗时任务是否需要开启子线程；为什么 IntentService 不需要手动开启。
5. SingleTask；被踢出的 Activity 是否销毁；Activity 在栈顶时的情况。
6. Activity A 启动 Activity B 的生命周期。
7. Glide 三级缓存；深入讲解活动缓存、内存缓存，以及两者区别。
8. RxJava 如何实现异步，是否看过源码。
9. 内存缓存大小。
10. View 的显示、测量、布局和绘制流程。
11. 写一个单例。
12. volatile。
13. 写一个带泛型方法的类。
14. 写一个拥有两个成员变量的自定义注解。
15. 多态。
16. 从前 n 个数中取前 k 大，说明时间复杂度，并在不使用 API 的情况下实现。
17. 最小生成树。
18. 一张图片如何在内存缓存、活动缓存、磁盘缓存之间流转；从磁盘缓存进入内存缓存后，图片是否还在磁盘缓存中。
19. 事件分发。
20. 汉诺塔，写伪代码。
21. 非递归和递归快速排序。
22. Java 的 sleep 和 wait 的区别。
