## 一面

### 自我介绍 / 项目背景

1. 自我介绍
2. 你的 App 在哪些应用商店上架？当前用户规模是多少？
3. 这个 App 分了哪几个主要模块（功能）？

### 社交 / 即时通讯相关

4. 社交功能是什么样的？有没有即时通讯/聊天？
5. 聊天功能是怎么实现的？消息发送/接收的流程是什么？
6. 聊天消息怎么存储（server / DB / 消息队列等）？群组、好友列表、通讯录是怎么管理的？
7. 消息推送你接入了哪些厂商（如 APNs、小米等）？到达率和典型延迟是多少？

### 技术选型 / 跨平台

8. 为什么选择 Flutter 做跨平台开发？优点和限制是什么？
9. 如果需要用到原生平台能力，如何在 Flutter 中与原生通信（如何实现、常用方案）？
10. 你了解 Flutter 的渲染流程吗？和 Android 原生渲染有什么差异？具体的渲染树（Widget/Element/RenderObject/Layer）是如何协作的？

### Dart / 并发 / 内存

11. 你了解 Dart 的 Isolate（或类似并发模型）吗？什么时候适合用 Isolate？内存是否隔离？
12. 在多线程/并发场景中，如何保证线程安全？synchronized 和 ReentrantLock 有什么区别？公平锁与非公平锁是什么？
13. 线程池（ThreadPool）创建时有哪些核心参数？每个参数的作用是什么？

### Android / 底层机制

14. Android 的进程间通信（Binder）原理是什么？除了 Binder，还有哪些进程间通信方式？各自适用场景是什么？
15. 为什么 Linux 已经有很多跨进程通信方式了还要用 Binder？
16. Android 自定义 View 的绘制流程（create → measure → layout → draw）了解多少？自定义组件通常怎么实现？
17. Handler 的作用？

### 图片 / 缓存 / 网络

18. 项目中用到哪些图片库？图片加载库一般有几级缓存（内存/磁盘/协商/强缓存）？缓存的淘汰策略如何实现（LRU、LFU等）？
19. 网络层你用的是什么（如 dio 等）？

### GC / 内存回收

20. Java 的垃圾回收（GC）策略你了解多少？分代回收（新生代/老年代）基本思想是什么？常见回收算法有哪些？

### 算法 / 编程题

21. 请写出一个算法：求二叉树的最大深度（并说明思路）。

### 反问

22. 团队主要是做什么？（动态化/小程序容器，RN，WebView）
