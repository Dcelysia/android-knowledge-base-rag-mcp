## 面试题

1. 过往项目中如何进行 React Native 容器的性能优化。
2. native DSL 容器出现渲染异常时的排查和解决步骤。
3. Web 容器动态化原理，以及如何保证其在小红书 App 中的安全性。
4. 组件化开发中的组件通信和依赖管理。
5. 引入业界前沿动态化技术并落地的经历、挑战与解决方案。
6. 设计新的多端动态化方案时的切入点。
